# Cruisin
Cruisin is a lightweight Android utility designed for couples, families, and roommates sharing a single vehicle. Running silently in the background, it requires zero manual input: tracking starts the moment your phone connects to the car's Bluetooth and ends automatically when the engine is turned off. Cruisin syncs trip telemetry (duration, distance, average speed) and the vehicle’s live parked location across all shared drivers in real time.

Hands-Free Drive Detection: Auto-starts and finishes tracking via native Bluetooth triggers.

Live "Where Did I Park?" Sync: Instant car location with automated address and zone labeling (e.g., Home / Work).

Shared Trip Feed: Synchronized dashboard showing recent drives, driving stats, and driver profiles powered by Supabase.

Zero-Hassle Pairing: Connects devices instantly using a simple shared car code and driver name.
